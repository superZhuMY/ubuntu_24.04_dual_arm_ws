## 三、E.4 执行逻辑（真机流程）

```text
双臂同时接入（test_arm=none，两臂均 REAL）
→ E.3 安全流程：打开设备 → 2 次稳定全读 → 各自命令缓存=反馈 → 打印首命令表 → 0x0303 使能
→ E.4 静态保持（默认 50 周期 ≈10s，操作者观察无突跳/漂移/报警）
→ 逐关节回零：每周期只改变选中关节目标，其余 5 关节=本次反馈
   目标 = 当前反馈 + 有符号小步（≤ e4_step_rad），单调逼近 0 rad，不越过零位
   到达 |err| ≤ e4_tol_rad → 保持 e4_hold_cycles → 下一关节
→ 全部到达 0 后保持，不再返回起始位置
→ 任一异常（读/写错误阈值、使能失败、关节超时、跟随误差>0.05rad×3）→ E4SharedStop
   → 两臂同时冻结目标（保持反馈），操作者 Ctrl-C/急停 → 原停止流程关闭双臂
```

首周期保证：`e4_compute_next_step()` 在进入分步前先执行“保持当前反馈”一周期，因此**第一条真实位置命令 == 本次读取的真实位置**（满足 E.4 §七.3）。

## 六、初始化 / 运动周期 / 停止阶段的全部真实写操作（每臂）

### 6.1 初始化（E.3 使能，稳定读取 2 次后）

对每个 Modbus 从站 1,2,3：读 `0x0303`；若值为 0 → 写 `0x0303 = 0x0001`。

### 6.2 运动/保持周期（5 Hz）

串口（J5→J6→J4，每电机）：flush → A3 位置写（14B）→ 1ms → 0x92 读 14B。

Modbus（J3→J2→J1，每从站）：写 `0x0305=0` → 1ms → 写 `0x110C`（2 寄存器，低字在前）→ 1ms → 写 `0x0305=1` → 读 `0x0B07`。

### 6.3 停止

对每个从站：写 `0x0303=0` ×2（间隔 110ms）→ 关闭串口/Modbus。

## 七、任一异常时两臂共同停止的实现路径

`E4SharedStop` 为进程内共享原子标志（左右臂同一 `ros2_control_node` 进程）。触发条件：

1. 任一臂连续读/写错误达到阈值（默认 5）；
2. 任一臂 0x0303 使能失败；
3. 任一臂当前关节超时（默认 60s）；
4. 任一臂跟随误差 > 0.05 rad 连续 3 周期；
5. 程序退出 / Ctrl-C / 急停。

触发后：**两臂均停止生成新目标**，命令保持当前反馈（无运动、无新位置命令）；操作者执行 Ctrl-C → 两臂各自走原停止流程（0x0303=0 ×2/从站 + 关闭）。不自动重试、不自动反向补偿。
