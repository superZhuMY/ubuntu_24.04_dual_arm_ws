## 四、已发现需注意/需决策的问题

1. **R_Joint_2 停靠位置超出 URDF 上限**：E.4 停止后 R_J2 反馈约 +0.0164 m，而 URDF 上限为 +0.01 m（L_J2 为 +0.0097，勉强在内）。真机 E.5 前需先将两臂关节重新带回 URDF 限位内（例如 E.4 回零流程后再进入 E.5），或确认 URDF 限位是否需要修正——未确认前不得对超限关节规划；
2. **L_Joint_3 略低于 URDF 下限**：当前约 −0.0007 m，下限为 0（差 0.7mm，MoveIt 可能按边界钳制）；建议先回到限位内；
3. **20 Hz 持续 overrun**：E.5 使用 5 Hz 配置；实际周期约 321ms（≈3.1 Hz），仍会报 overrun 但不影响分步下发；
4. **Python MoveIt 接口缺失**：`moveit_commander`/`moveit_py` 未安装；系统 Python（`/usr/bin/python3`，含 yaml 与 moveit_msgs）可用，E.5 工具采用纯 rclpy+moveit_msgs 实现；裸 `python3` 是 conda 3.14（缺 yaml），**必须用 `/usr/bin/python3` 运行工具**；
5. **J2 重力特性**（E.4 已记录）：失能前需确认机械支撑/安全姿态。
